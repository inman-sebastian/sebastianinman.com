# sebastianinman.com

Portfolio & services site for Sebastian Inman: automation and AI integration
for small businesses, based in Southern Oregon.

Built with Next.js (App Router) + Tailwind CSS. All copy lives in `content/`
as MDX; the site is designed to be managed by editing content files, not
code. **See [CLAUDE.md](./CLAUDE.md) for the full guide**: voice rules,
project map, and recipes for adding services, pages, and SEO landing pages.

```bash
npm install
npm run dev   # http://localhost:3000
```
